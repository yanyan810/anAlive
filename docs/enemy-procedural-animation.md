# 敵の簡易Procedural Animation

`Game/enemy/EnemyProceduralAnimation.h` に描画用の計算を分離しています。
Tポーズを基準に毎回Transformを再計算し、前フレームの描画Transformには加算しません。
通常・片脚欠損では残っている左右の腕を肩から約72度下げ、移動中は下げた腕を前後に振ります。停止時も腕を下げた基本姿勢を維持します。

- 両脚あり：移動中のみ全身の小さな上下動と肩・股関節を支点にした腕・脚の振り。
- 片脚欠損：欠損側への傾きに、移動中の左右揺れ・上下動・残った脚の振りを追加。
- 両脚欠損：胴体を約85度倒したうつ伏せ姿勢。腕を前に伸ばし、移動中は左右交互に前へ出して引く動きで身体を引きずります。上下動と胴体の小さな揺れも加えます。

状態は部位の `Destroyed()` で判定します。Head/Bodyを含む現在の部位管理とHPルールは変更していません。
LeftLeg/RightLeg/LeftArm/RightArmという部位名で左右を識別します。可変部位のGenericなArm/Legには左右を推測せず、全身補正のみ適用します。
脚の名前が一つもないモデルは通常姿勢です。描画チェックボックスで非表示にするだけでは欠損状態になりません。

`Enemy::Update` のAI移動前後のXZ座標差を使って、実際に移動したフレームだけsin波の時間をdeltaTimeで進めます。
`UpdateVisuals(0)` による当たり判定・デバッグの再更新では時間は進みません。
停止時は動的な振りを止め、欠損時の傾き・高さ補正を維持します。Idle/攻撃の専用モーションはありません。
Showroomで敵をFreezeした場合は時間が停止します。

`EnemyProceduralAnimationSettings` が調整箇所です。Hzは1秒あたりの周期、角度はラジアン、上下動と高さ低下は基準モデル全高に対する割合です。

| 設定 | 初期値 | 用途 |
| --- | --- | --- |
| walkHz / crawlHz | 1.6 / 1.1 | 移動の揺れ速度 |
| walkBob | 0.008 | 通常・片脚の上下動 |
| armLowerAngle | 1.25 | Tポーズから腕を下げる角度（約72度） |
| armSwing / legSwing | 0.10 / 0.065 | 通常・片脚移動の腕、通常移動の脚の振幅 |
| missingLegLean / missingLegSway | 0.075 / 0.025 | 欠損側の傾き・左右揺れ |
| remainingLegSwing | 0.09 | 片脚時の残った脚の振幅 |
| crawlGroundClearance | 0.015 | 両脚欠損時に描画部位を基準地面から浮かせる高さの割合 |
| crawlForwardLean | 1.48 | 両脚欠損時の前傾（約85度、うつ伏せ） |
| crawlBob / crawlSway | 0.006 / 0.025 | 這い移動の上下動・左右揺れ |
| crawlArmReach | 1.10 | 這う腕を頭側へ伸ばす基本角度 |
| crawlArmStroke | 0.30 | 左右交互の腕の伸ばし・引き幅 |
| crawlArmPlant | 0.22 | 腕を下向きにして身体を支える角度 |

モデル座標は既存Bossに合わせて上+Y、左+Z、前-Xです。非均等スケールや敵の向きも考慮して補正します。
元のモデル頂点・基準Transformは変更しません。描画用Object3dの姿勢を補正し、部位Raycastと部位判定枠にもそのObject3dの現在のワールド行列を使います。
移動コライダー・敵同士の押し合い・AIは引き続き元の移動座標を使います。Bomberの起爆中心とデバッグの頭位置は、現在の描画部位に合わせます。
全身モデルのフォールバックも専用の描画オブジェクトを初期化時に用意し、基準TransformとGPUバッファを分離します。
部位判定は通常移動、片脚欠損、うつ伏せ、腕の振りすべてに追従します。JSON部位と旧Bossの分割部位は、モデル表面の三角形で命中を判定します（先に部位のローカルAABBで絞り込み）。三角形データがないフォールバックは姿勢に追従するAABB判定です。
破壊済み・描画上非表示の部位には当たりません。複数の部位に交差する場合は、世界座標の距離で最も手前の部位を選びます。旧Bossの部位Boundsも実際の分割モデルに合わせ、形状データは初期化時に共有してプール再出現時に読み直しません。
うつ伏せの高さは生き残った各部位の基準AABBを描画姿勢へ変換した最下点から計算し、Enemyの基準Yを地面として全身を持ち上げます。腕・胴体の支点は保ち、描画上の床への埋まりを抑えます。実際の地形を問い合わせる接地処理やIKは行いません。
片腕だけ残っている場合はその腕を動かし、両腕とも失った場合は胴体の揺れだけで移動します。停止中はうつ伏せと腕を前へ出した支持姿勢を維持します。
破壊時の破片は既存処理により、その時点の描画Transformから生成されます。
EnemyPoolの再出現では位相・移動状態をリセットし、デバッグタイムラインではアニメーション状態も保存・復元します。

見た目確認はDebugのShowroomで敵を動かし、片脚・両脚を射撃して破壊してください。
Enemyの `Procedural Animation` チェックで基準姿勢と比較でき、`Movement Pose` に選択中の状態が表示されます。
`Arm Pose Tuning` で腕を下げる角度と前後振りの振幅をその場で調整できます（選択中の敵のみ、JSONへの保存はありません）。
`Crawl Pose Tuning` でうつ伏せ角度、地面からの高さ、腕を前へ出す角度、腕の動き幅、這う周期を調整できます（選択中の敵のみ）。調整後の部位判定も同じ姿勢に更新されます。
`Show Enemy Part Colliders` で姿勢に追従する部位枠、`Show Enemy Movement Collider` で従来の移動用円柱を確認できます。部位枠は三角形を囲う箱なので、枠内でもモデル表面のない空間には命中しません。

検証：`tools/test-enemy-animation.ps1`、既存の部位・敵タイプ・EnemyPoolテスト、Debug/Releaseビルド。
